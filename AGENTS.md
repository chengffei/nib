# AGENTS.md

Conventions for anyone (people or coding agents) changing Nib. User-facing docs are in README.md.

## Layout

| Path | What it is |
|---|---|
| `Nib/*.swift` | The macOS shell: SwiftUI windows, menus, tabs, sidebar, search, file I/O, export |
| `Web/src/` | The editor core: CodeMirror 6 with live preview, tables, read view, find bar |
| `Nib/Editor/` | Build output of `Web/` (committed). After changing `Web/src`, run `npm run build` in `Web/` |
| `scripts/` | Checks, performance harness, DMG and website builders |
| `docs/` | The website (GitHub Pages), generated by `scripts/site/build.py` |

## Dependency direction

- The shell talks to the core only through `window.nib.*` calls (`EditorWebView.send`) and `post({ type })` messages back.
  Neither side reaches into the other's internals.
- Pure logic lives in files with no UI imports, so it can be checked without the app or a browser:
  - Swift, Foundation / ImageIO only: `Pinyin.swift`, `ImageSizes.swift`. Checked by `scripts/unit/run.sh`.
  - JS, no DOM or CodeMirror at import time for the tested functions: `tableColumns.js` (`distribute`). Checked by `npm test`.
  New logic that can be pure should go in such a file, with checks.
- Core modules import downward only: `main.js` → feature modules (`livePreview`, `table`, `readView`, …) → helpers
  (`tableColumns`, `i18n`). Helpers never import `main.js`.

## Checks (run before committing)

| Command | Covers |
|---|---|
| `cd Web && npm test` | Pure JS rules (table width distribution) |
| `sh scripts/unit/run.sh` | Pure Swift rules (pinyin matching, image header sizes) |
| `swift scripts/webcheck.swift scripts/fixture.md /tmp/out.png light "return nib.mode()"` | Loads the built core offscreen; must print `round-trip identical: true` |
| `sh scripts/perf/run.sh` | Performance baseline; compare with `scripts/perf/README.md` |

- No fixed sleeps in checks: webcheck starts when the editor reports `ready` and settles by waiting for rendered frames.
  Wait for an event or a frame, not for time.
- Saving must stay byte-exact: untouched lines, line endings and blank lines never change.

## Style

- English for code, comments and commit messages (Conventional Commits). Localised strings stay in their own language files.
- New UI strings: add to `zh-Hans.lproj` first (the full set), then the other languages; core strings go in `Web/src/i18n.js`.
- Nib is read-first: when reading and editing conflict, reading wins. No plugins, sync or accounts; no raw HTML rendering.
