Qu’est-ce que Nib ?

Nib est une app Markdown gratuite et open source pour Mac qui ouvre les fichiers mis en forme, comme un document, et non comme du code. Appuyez sur ⌘E pour éditer sur place : seule la ligne où vous êtes affiche son Markdown, comme dans Typora. L’enregistrement ne réécrit que vos modifications, le fichier reste donc propre pour git. Nib recharge les fichiers modifiés par d’autres programmes, réunit tous les documents en onglets dans une seule fenêtre et cherche dans des dossiers entiers. App native, environ 8 Mo, macOS 15 ou plus récent.

Lire d’abord. Éditer sur place.

Pendant que vous lisez, ce n’est qu’une page.

  • S’ouvre mis en forme. Titres, tableaux, listes de tâches et code, bien présentés. Les liens fonctionnent. Rien à modifier par mégarde.
  • ⌘E pour éditer. Seule la ligne où vous êtes affiche son Markdown. Le reste reste mis en forme.
  • Les niveaux d’un coup d’œil. De petites marques H1–H6 dans la marge pendant l’édition.
  • ⌘/ pour la source. Tout le fichier en chasse fixe, à une touche.

Votre fichier, intact.

Changez un mot, et git diff montre un mot.

  • Réécrit tel quel. Fins de ligne, lignes vides, indentation et lignes non touchées restent identiques à l’octet près.
  • Rien d’ajouté. Pas de métadonnées, pas de reformatage, pas de fichiers cachés.
  • Pas de scripts. Le HTML brut n’est pas interprété : un fichier téléchargé s’ouvre sans risque.

Pour le Markdown qu’écrivent vos outils.

Plans des agents de code. Rapports de scripts. Docs des outils de build. Vous les lisez surtout, et corrigez une ligne de temps en temps.

Rechargé en 0,1 s

Quand un terminal, un script ou un agent réécrit un fichier, la page ouverte se met à jour toute seule.

Une fenêtre, plusieurs onglets

Fichiers du Finder, du terminal ou d’un lien : tout rejoint une seule fenêtre. ⌘1–⌘9 pour passer de l’un à l’autre.

Un espace de travail avec pastilles git

Les fichiers modifiés ont une pastille orange, les nouveaux une verte. Elles disparaissent dès que vous faites un commit.

Tout retrouver

⇧⌘O ouvre par nom. ⇧⌘F cherche dans tous les fichiers et saute à la ligne. 2 500 fichiers en moins de 0,25 s.

Toujours prêt

Fermez la dernière fenêtre : Nib quitte le Dock mais reste prêt. Le fichier suivant s’ouvre en 0,15 s environ.

Onglets en veille

Les onglets que vous n’avez pas regardés depuis un moment libèrent leur mémoire et se réveillent là où vous les aviez laissés.

Nib face à Typora, MarkEdit et Obsidian

Typora a fixé la référence de l’édition sur place. MarkEdit est un éditeur de source natif et rapide. Obsidian est tout un système de notes. Nib sert à lire du Markdown, et à le corriger au besoin.

Installer

Nib n’est pas notarisé par Apple. Autorisez-le une fois au premier lancement.

Télécharger Nib.dmg

Glissez dans Applications

Ouvrez Nib.dmg et glissez Nib dans le dossier Applications.

Autorisez-le une fois

Ouvrez-le et cliquez sur Terminé. Puis, dans Réglages Système › Confidentialité et sécurité, cliquez sur Ouvrir quand même.

Faites-en l’app par défaut

Sélectionnez un .md dans le Finder, appuyez sur ⌘I, choisissez Nib sous Ouvrir avec, puis cliquez sur Tout modifier.

Requiert macOS 15 ou plus récent. App universelle pour Apple silicon et Intel.

FAQ

Les questions les plus fréquentes.

Existe-t-il une alternative gratuite et open source à Typora sur Mac ?

Nib édite le Markdown sur place comme Typora : seule la ligne où vous êtes affiche sa syntaxe. Il est gratuit, open source sous GPL-3.0 et natif sur Mac. Contrairement à Typora, il ouvre d’abord les fichiers en lecture ; appuyez sur ⌘E pour éditer. Il accepte aussi les thèmes Typora.

Comment lire les fichiers Markdown écrits par des agents de code comme Claude Code ou Codex ?

Faites de Nib l’app par défaut pour les fichiers .md, puis cliquez sur le chemin du fichier dans votre terminal ou ouvrez-le depuis le Finder. Il s’ouvre mis en forme, dans un onglet de la fenêtre déjà ouverte, et se recharge tout seul quand l’agent réécrit le fichier. Ajoutez le dossier du projet à la barre latérale pour voir quels fichiers ont changé depuis le dernier commit.

Nib modifie-t-il mes fichiers Markdown ?

Seulement là où vous éditez. L’enregistrement réécrit vos modifications et garde tout le reste à l’octet près, fins de ligne et lignes vides comprises. Nib n’ajoute aucune métadonnée et ne crée aucun fichier caché.

Puis-je utiliser des thèmes Typora ?

Oui. Placez le fichier CSS du thème et son dossier dans ~/Library/Application Support/Nib/themes, puis choisissez-le dans les Réglages. La vue lecture utilise tout le thème ; l’éditeur reprend ses couleurs et ses polices. Nib lit ce format mais n’inclut aucun thème Typora.

Nib est-il gratuit ?

Oui. Nib est gratuit et open source sous GPL-3.0. Pas de compte, rien à acheter.

Pourquoi macOS dit-il qu’il ne peut pas vérifier le développeur ?

Nib n’est pas notarisé par Apple. Ouvrez-le une fois, fermez l’avertissement, puis allez dans Réglages Système › Confidentialité et sécurité et cliquez sur Ouvrir quand même. Une seule fois suffit.

Nib prend-il en charge les maths ou les diagrammes Mermaid ?

Pas encore. Les blocs de code marqués math ou mermaid s’affichent comme du code.
