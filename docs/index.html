What is Nib?

Nib is a free, open-source Markdown app for Mac that opens files rendered, like a document, instead of as code. Press ⌘E to edit in place: only the line you’re on shows its Markdown, the way Typora works. Saving writes back only your edits, so the file stays clean for git. It reloads files that other programs change, keeps every document as a tab in one window, and searches whole folders. Native app, about 4 MB, macOS 15 or later.

Read first. Edit in place.

While you read, it’s just a page.

  • Opens rendered. Headings, tables, checklists and code, laid out. Links work. Nothing to type into by accident.
  • ⌘E to edit. Only the line you’re on shows its Markdown. The rest stays rendered.
  • Levels at a glance. Small H1–H6 marks in the margin while you edit.
  • ⌘/ for source. The whole file in monospace, one key away.

Your file, untouched.

Change one word, and git diff shows one word.

  • Written back as is. Line endings, blank lines, indentation and untouched lines stay byte for byte.
  • Nothing added. No metadata, no reformatting, no hidden files.
  • No scripts. Raw HTML isn’t rendered, so a downloaded file is safe to open.

For the Markdown your tools write.

Plans from coding agents. Reports from scripts. Docs from build tools. You mostly read them, and now and then fix a line.

Reloads in 0.1 s

When a terminal, script or agent rewrites a file, the open page updates on its own.

One window, many tabs

Files from Finder, the terminal or a link all join one window. ⌘1–⌘9 to switch.

A workspace with git dots

Changed files get an orange dot, new ones green. They clear as soon as you commit.

Find anything

⇧⌘O opens by name. ⇧⌘F searches every file and jumps to the line. 2,500 files in under 0.25 s.

Always ready

Close the last window and it leaves the Dock but stays ready. The next file opens in about 0.15 s.

Sleeping tabs

Tabs you haven’t looked at in a while give back their memory and wake up where you left them.

Install

Nib isn’t notarized by Apple. Allow it once on first launch.

Download Nib.dmg

Drag to Applications

Open Nib.dmg and drag Nib into the Applications folder.

Allow it once

Open it and click Done. Then in System Settings › Privacy & Security, click Open Anyway.

Make it the default

Select a .md in Finder, press ⌘I, choose Nib under Open with, and click Change All.

Requires macOS 15 or later. Universal app for Apple silicon and Intel.

FAQ

The questions people ask most.

Is there a free, open-source alternative to Typora for Mac?

Nib edits Markdown in place the way Typora does: only the line you’re on shows its syntax. It’s free, open source under the GPL-3.0 and native to the Mac. Unlike Typora, it opens files in a read view first; press ⌘E to edit. It can also use Typora themes.

How do I read Markdown files written by coding agents like Claude Code or Codex?

Make Nib the default app for .md files, then click the file path in your terminal or open it from Finder. It opens rendered, in a tab of the window you already have, and reloads by itself when the agent rewrites the file. Add the project folder to the sidebar to see which files changed since the last commit.

Does Nib change my Markdown files?

Only where you edit. Saving writes back your changes and keeps everything else byte for byte, including line endings and blank lines. Nib adds no metadata and makes no hidden files.

Can I use Typora themes?

Yes. Put the theme’s CSS file and its folder in ~/Library/Application Support/Nib/themes and pick it in Settings. The read view uses the whole theme; the editor borrows its colors and fonts. Nib reads the format but ships no Typora themes.

Is Nib free?

Yes. Nib is free and open source under the GPL-3.0. There is no account and nothing to buy.

Why does macOS say it can’t verify the developer?

Nib isn’t notarized by Apple. Open it once and dismiss the warning, then go to System Settings › Privacy & Security and click Open Anyway. You only need to do this once.

Does Nib support math or Mermaid diagrams?

Not yet. Code blocks marked math or mermaid show as code.
