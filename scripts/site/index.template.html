What is Nib?Nib 是什么？

Nib is a free, open-source Markdown app for Mac that opens files rendered, like a document, instead of as code. Press ⌘E to edit in place: only the line you’re on shows its Markdown, the way Typora works. Saving writes back only your edits, so the file stays clean for git. It reloads files that other programs change, keeps every document as a tab in one window, and searches whole folders. Native app, about 6 MB, macOS 15 or later. Nib 是免费开源的 Mac Markdown 应用。它打开文件时直接显示排好版的文档，而不是源码。按 ⌘E 就地编辑，只有光标所在行露出 Markdown 语法，手感同 Typora。存盘只写回你的改动，文件在 git 里保持干净。别的程序改写了文件它会自动刷新，所有文档并在一个窗口的标签里，还能搜整个文件夹。原生应用，约 6 MB，需要 macOS 15。

先读，再改。Read first. Edit in place.

读的时候，它就是一页排好的文档。 While you read, it’s just a page.

  • 打开就是成品。标题、表格、清单、代码块排好版，链接直接点，不会误触改动。Opens rendered. Headings, tables, checklists and code, laid out. Links work. Nothing to type into by accident.
  • ⌘E 就地改。只有光标所在行露出语法，其余照样排好。⌘E to edit. Only the line you’re on shows its Markdown. The rest stays rendered.
  • 层级一眼可辨。编辑时左侧留白标出 H1 到 H6。Levels at a glance. Small H1–H6 marks in the margin while you edit.
  • ⌘/ 看源码。整篇等宽源码，随时切回。⌘/ for source. The whole file in monospace, one key away.

不动你的文件。Your file, untouched.

改一个词，git diff 里就只有这一个词。 Change one word, and git diff shows one word.

  • 原样写回。换行符、空行、缩进、没碰过的行，一个字节都不变。Written back as is. Line endings, blank lines, indentation and untouched lines stay byte for byte.
  • 不加私货。不写元数据，不改格式，不留隐藏文件。Nothing added. No metadata, no reformatting, no hidden files.
  • 不跑脚本。不渲染文件里的原始 HTML，下载来的文件也放心打开。No scripts. Raw HTML isn’t rendered, so a downloaded file is safe to open.

安装Install

Nib 没有经过 Apple 公证，第一次打开需要放行一次。 Nib isn’t notarized by Apple. Allow it once on first launch.

下载 Nib.dmgDownload Nib.dmg

拖进应用程序Drag to Applications

打开 Nib.dmg，把 Nib 拖进「应用程序」文件夹。Open Nib.dmg and drag Nib into the Applications folder.

放行一次Allow it once

先打开一次并点「完成」，再到「系统设置 › 隐私与安全性」点「仍要打开」。Open it and click Done. Then in System Settings › Privacy & Security, click Open Anyway.

设为默认Make it the default

在访达选中一个 .md，按 ⌘I，「打开方式」选 Nib，点「全部更改」。Select a .md in Finder, press ⌘I, choose Nib under Open with, and click Change All.

需要 macOS 15 或更高。通用应用，支持 Apple 芯片与 Intel。 Requires macOS 15 or later. Universal app for Apple silicon and Intel.

常见问题FAQ

最常被问到的几件事。The questions people ask most.

Is there a free, open-source alternative to Typora for Mac?Mac 上有免费开源的 Typora 替代品吗？

Nib edits Markdown in place the way Typora does: only the line you’re on shows its syntax. It’s free, open source under the GPL-3.0 and native to the Mac. Unlike Typora, it opens files in a read view first; press ⌘E to edit. It can also use Typora themes.Nib 的就地编辑和 Typora 一样，只有光标所在行露出语法。它免费、以 GPL-3.0 开源、是原生 Mac 应用。和 Typora 不同，它打开文件先进阅读视图，按 ⌘E 编辑。它也能用 Typora 主题。

How do I read Markdown files written by coding agents like Claude Code or Codex?怎么读 Claude Code、Codex 这类编程 Agent 写的 Markdown？

Make Nib the default app for .md files, then click the file path in your terminal or open it from Finder. It opens rendered, in a tab of the window you already have, and reloads by itself when the agent rewrites the file. Add the project folder to the sidebar to see which files changed since the last commit.把 Nib 设为 .md 的默认应用，然后在终端里点文件路径，或从访达打开。文件以排好的版面打开，并进已有窗口的标签里；Agent 改写文件时自动刷新。把项目文件夹加进侧栏，还能看到上次提交后改了哪些文件。

Does Nib change my Markdown files?Nib 会改动我的 Markdown 文件吗？

Only where you edit. Saving writes back your changes and keeps everything else byte for byte, including line endings and blank lines. Nib adds no metadata and makes no hidden files.只改你编辑的地方。存盘时写回你的改动，其余逐字节保持原样，包括换行符和空行。Nib 不写元数据，不留隐藏文件。

Can I use Typora themes?能用 Typora 主题吗？

Yes. Put the theme’s CSS file and its folder in ~/Library/Application Support/Nib/themes and pick it in Settings. The read view uses the whole theme; the editor borrows its colors and fonts. Nib reads the format but ships no Typora themes.能。把主题的 CSS 和同名文件夹放进 ~/Library/Application Support/Nib/themes，在设置里选。阅读视图完整套用主题，编辑时借用主题的颜色和字体。Nib 兼容格式，但不附带 Typora 的主题。

Is Nib free?Nib 免费吗？

Yes. Nib is free and open source under the GPL-3.0. There is no account and nothing to buy.免费，以 GPL-3.0 协议开源。没有账号，没有付费项。

Why does macOS say it can’t verify the developer?为什么 macOS 提示无法验证开发者？

Nib isn’t notarized by Apple. Open it once and dismiss the warning, then go to System Settings › Privacy & Security and click Open Anyway. You only need to do this once.Nib 没有经过 Apple 公证。先打开一次并关掉提示，再到「系统设置 › 隐私与安全性」点「仍要打开」。只需一次。

Does Nib support math or Mermaid diagrams?支持数学公式或 Mermaid 图吗？

Not yet. Code blocks marked math or mermaid show as code.暂不支持，这类代码块按代码显示。
